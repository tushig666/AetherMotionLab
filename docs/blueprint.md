# **App Name**: AetherMotion Lab

## Core Features:

- Cinematic Prompt Terminal: An AI-powered command center that uses specialized tools to translate natural language into structured, motion-ready SVG hierarchies.
- Generative Motion Engine: Orchestrates complex GSAP timelines based on scene intent, applying procedural staggering and physics-based easing to vector elements.
- Vector Topology Morpher: A high-end tool that calculates and animates the transformation of complex SVG paths between two disparate generated states using generative AI.
- Infinite Lab Canvas: A hardware-accelerated viewport with cinematic depth-of-field effects, real-time lighting passes, and an immersive stage for SVG playback.
- Live Kinetic Inspector: A professional-grade panel to inspect and live-edit generated SVG markup and GSAP choreography code with real-time syncing.
- Persistence Registry: Securely stores user generations, prompt history, and animation metadata within a cloud database for seamless workspace persistence.
- Professional Pipeline Export: Generates a complete standalone package including production-ready HTML, CSS, and optimized JS/GSAP assets.

## Style Guidelines:

- Primary Color: Vivid Ultraviolet (#7C3AED) - A striking, energetic purple that signifies AI creativity and cinematic high-tech elegance.
- Background Color: Obsidian Void (#07070D) - A deep, desaturated space-blue with just enough warmth to create an expensive, atmospheric dark theme.
- Accent Color: Electric Cyan (#22D3EE) - An analogous high-contrast hue used for active AI thinking indicators and glowing interface interactive states.
- Font Recommendation: 'Space Grotesk' for tech-forward headlines and functional UI labels, paired with 'Inter' for longer descriptive text and code metadata.
- Code Font: 'Source Code Pro' used for all vector hierarchy and animation logic inspection panels to ensure readability in deep editor contexts.
- Icons are minimalist glassmorphic outlines with a 1px border thickness and subtle glow filters to maintain the futuristic holograph aesthetic.
- An ultra-premium cinematic IDE layout with a collapsible sidebar 'floating' on a noise-textured grid, providing maximal visual focus on the center Stage.
- UI transitions use exponential easing for an elite, responsive feel; the generation stage uses fluid morphs and staggered entries.
